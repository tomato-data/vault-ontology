# Phase 3 — vault 스캔과 링크 해석

> 모듈: `vault/scan.py` · scope: `scan`

## 큰 그림

Phase 2까지는 **문서 하나**를 읽었다. 여기서는 vault 전체를 훑고, 링크가 가리키는 **이름을 실제 파일로 해석**한다.

```
scan_vault(root)              →  파일 목록 · 이름 인덱스
resolve_link(target, index)   →  링크 대상 → 실제 경로 | None
```

## 이전 Phase와의 연결

Phase 2의 `iter_links`가 뱉는 건 **문자열**이다. `[[CIDR]]`의 `CIDR`은 아직 아무것도 가리키지 않는다. 여기서 그 문자열이 파일이 된다.

## 핵심 개념

### 이 Phase가 온톨로지 학습의 진짜 시작이다

표면적으로는 파일 탐색이지만, 실제로 푸는 문제는 이것이다.

> **이름은 식별자가 아니다.**

Obsidian의 위키링크는 **파일명으로** 문서를 가리킨다. 파일명은 바뀌고, 겹치고, 운영체제마다 다르게 정규화되고, 대소문자를 구분하기도 안 하기도 한다. 그런 걸 식별자로 쓰면 어떤 일이 생기는지를 6,452개 실물에서 겪는다.

**Phase 6에서 IRI를 설계할 때 이 경험이 그대로 재료가 된다.** RDF는 모든 것에 전역 식별자(IRI)를 요구하는데, "파일 경로로 할까 이름으로 할까 안정적인 ID를 새로 줄까"가 그때의 첫 결정이다. 지금 겪는 고통이 그 결정의 근거가 된다.

### 함정 넷

**1. 유니코드 정규화 (NFC / NFD)**

macOS 파일시스템은 파일명을 **NFD**(자모 분리)로 저장한다. `한글` 세 글자가 자모 여섯 개로 들어 있다. 그런데 문서 본문에 타이핑한 `[[한글]]`은 **NFC**다.

```
os.listdir() 이 준 이름   ㅎㅏㄴㄱㅡㄹ   (NFD, 6 코드포인트)
본문에서 읽은 링크 타깃    한글          (NFC, 2 코드포인트)
                          ↑ 문자열 비교가 실패한다
```

눈으로는 똑같이 보인다. **한국어 vault에서 이걸 안 맞추면 링크가 대량으로 깨진 것으로 잡힌다.** 양쪽 다 `unicodedata.normalize("NFC", s)`를 통과시킨다.

**2. `os.path.splitext`를 쓰면 안 된다**

```python
os.path.splitext("No.013 현자의 돌.md")
→ ("No.013 현자의 돌", ".md")     ← 맞다

os.path.splitext("No.013 현자의 돌")   # 확장자가 이미 없는 경우
→ ("No", ".013 현자의 돌")             ← 쪼개진다
```

`.md`만 명시적으로 뗀다. `removesuffix(".md")`.

**3. 대소문자**

macOS 기본 파일시스템은 대소문자를 **보존하지만 구별하지 않는다**. `python.md`와 `Python.md`가 공존할 수 없다. 그런데 Linux에서 clone하면 공존한다. 이름 인덱스를 만들 때 **대소문자 무시 충돌을 따로 감지**해야 나중에 플랫폼을 옮겨도 안 터진다.

**4. 동명이인**

`Hub.md`가 vault에 여러 개 있다. `[[Hub]]`는 어디를 가리키나?

Obsidian은 "가장 가까운 것"을 고르지만, 그래프 빌더는 그 규칙을 그대로 흉내 내기 어렵다. **답안지의 대응은 「거부」였다** — `vault new`가 같은 파일명 중복을 만들지 못하게 막았다. 검출이 아니라 예방이다.

### 링크 해석 규칙

Obsidian의 실제 동작을 근사한다.

```
1. 이름 그대로 인덱스에 있나            [[CIDR]] → CIDR.md
2. `/` 가 있으면 경로로 본다            [[203 Backend/CIDR]]
3. 경로 꼬리 매칭                       …/203 Backend/CIDR.md 로 끝나는 것
4. 없으면 미해결
```

미해결이 곧 오류는 아니다. **세 부류**이고 처리가 다르다 (스키마 정본 Phase 3.5).

| 부류 | 예 | 처리 |
|---|---|---|
| 자리표시자 | `...` `참조` `{완제품}` | 템플릿 문법. 건드리지 않는다 |
| 외부 참조 | `monthly-elevate` | 스킬은 vault 밖에 실재한다 |
| 진짜 유실 | 어디에도 없는 이름 | git 이력 → 유사도 → 제거 |
